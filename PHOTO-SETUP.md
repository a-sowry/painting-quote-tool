# Accounts, photo measuring and roof measuring — setup

Do these once, in order. Never paste secret keys into chat or into the code — only into the Supabase Secrets page.

## 1. Database (accounts + saved quotes)
Supabase > SQL Editor > New query > paste all of `supabase/schema.sql` > Run.

## 2. Sign-in settings
Supabase > Authentication > URL Configuration:
- Site URL: `https://a-sowry.github.io/painting-quote-tool/`
- Redirect URLs: add the same address.

Optional while testing: Authentication > Sign In / Providers > Email > turn **Confirm email** off, so sign-up logs you straight in.

## 3. Photo measuring function (redeploy)
Edge Functions > `analyse-photo` > Code: replace everything with `supabase/functions/analyse-photo/paste-into-dashboard.ts` > Deploy. Verify JWT stays **off**.

## 4. Roof measuring function (new)
Edge Functions > Deploy a new function > Via Editor > name it `roof-measure` > paste `supabase/functions/roof-measure/paste-into-dashboard.ts` > Verify JWT **off** > Deploy.

## 5. Google key (roof measuring)
1. console.cloud.google.com > create a project > enable billing (needed even for the free allowance).
2. APIs & Services > Library: enable **Geocoding API** and **Solar API**.
3. Credentials > Create API key. Restrict it to those two APIs.
4. Supabase > Edge Functions > Secrets: add `GOOGLE_MAPS_API_KEY` = that key.
5. Check Google's current Solar API pricing and set a budget alert before inviting other painters.

## 6. Limits (optional)
Secrets `MONTHLY_PHOTO_LIMIT` and `MONTHLY_ROOF_LIMIT` set how many lookups each signed-in painter gets per month (the code has defaults). Your own `ACCESS_CODE` (Settings > Owner access code) is unlimited.

## Notes
- Roof measuring works where Google has Solar data. Australian coverage is partial, so some addresses will say "no data"; type the roof area in by hand then.
- The roof button only shows when the **Roof** service is ticked in Prices/services.
- `core.mjs` files are the tested source; `paste-into-dashboard.ts` is generated by `python3 tools/build-paste.py`.
